# 員工端：一次安裝，每天自動交

使用v0.2。AI先讀根目錄SETUP.md。**新版入口在daily/install-windows.ps1**；本目錄原install-windows.ps1／install-macos.sh屬舊伺服器流程，不要沿用。

提供三項：姓名（與老闆名單完全一致）、公司同步資料夾本機位置、允許回報的公司專案範圍。老闆需先初始化收件夾；不要把GitHub程式目錄當日報收件夾。

預設只有數字與專案名；若同意分享工作請求短片段，安裝時開啟excerpts。工具不看螢幕、不記鍵盤，也不知道你整天做的所有工作。

每日17:00交截至當時報告，登入／每30分鐘補交更新；隔日補成整日版。關機時不能交，恢復登入再補。不必每天叫AI，日常排程不消耗模型Token。

漏交時，按安裝目錄「立即補交今天」。存入同步路徑後，仍以老闆端收到為準。狀態在data/last-run.log及daily-status.json。

程式、設定設唯讀並有指紋檢查；改MD不影響計算。驗證失敗請協助者核對重裝，不自行關閉保護。這是防誤改，不保證能阻擋電腦主人刻意修改。
