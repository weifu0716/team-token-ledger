# v0.2 計數與驗證

来源是CODEX_HOME內sessions與archived_sessions JSONL，解析session_meta、turn_context、response_item user（opt-in）、event_msg/token_count。格式變動、雲端未落地或刪除都可能漏算。

1. 以安裝時固定UTC偏移的00:00到次日00:00歸日。17點先交當時版本，隔日補整日；事件以token_count時間歸屬，不估分跨午夜單次請求。
2. 安裝首日包含當天已有用量。更早日期不產報，但可本機讀歷史快照建立差值。
3. 同檔累計相減，相同快照跳過。第一快照只用last_token_usage，避免把fork繼承前綴算入今天，歷史不完整提示。
4. total=input+output；cached是input子集，reasoning是output子集，不再次相加。來源有total_tokens時也核對。
5. 非整數、負數、子集超出、倒退、破損、半行等保守跳過並提示，不估補。
6. 指紋=UTC時間＋累計計數，不含session ID以抓複製／fork改名。极少數獨立同時同數事件可能被視為重複。
7. 同台去重，跨人同事件在兩邊提示，全部排除無爭議合計。另一人晚交可能使團隊去重總數下修。
8. 重新掃描仍存在的本機紀錄；刪來源可能令新版變少。老闆保留已見高水位，持續提醒明細减少／總量下降。
9. 老闆從快照重算delta、日期、去重、小計與總數，再核對PDF SHA-256。**同一批資料必須完全一致，不能只求差不多。**

三個口徑要分開：個人報告=該安裝觀測值；團隊無爭議合計=已收到可核對且排除跨人重複的事件；官方帳號總量=本工具目前沒有來源，不能拿訂閱剩餘百分比換算。

同人多機不合併，可用姓名（裝置）區分。共用帳號是否同步工作需實機驗證；本機落地不等於本人發起。

PDF指紋不是簽章。一起偽造核對檔及原始來源仍可能算得攏，只提供收件管理與一致性檢查。
